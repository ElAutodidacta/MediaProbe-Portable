Interpretación y límites

CID/CSD/OCR

Un lector USB suele ocultar los registros SD. En Linux, un controlador directo SD/MMC puede exponerlos como mmcblk; Windows normalmente no dispone de una API genérica. Ningún software puede leer lo que el puente no transmite. Un CID plausible tampoco certifica originalidad.

USB y cuello de botella

La velocidad del enlace solo se indica si el sistema la expone. xHCI no demuestra que el dispositivo haya negociado USB 3.x. El límite teórico Mb/s ÷ 8 no incluye sobrecarga; el diagnóstico del lector es una hipótesis, no una certeza.

Clase SD

C10/U1/V10 son referencias de 10 MB/s; U3/V30 de 30, V60 de 60 y V90 de 90. A1 pide 1500/500 IOPS y 10 MB/s; A2, 4000/2000 y 10. MediaProbe compara observaciones de archivos, no ejecuta el método de certificación SD ni comprueba Command Queueing.

Capacidad y sectores

Una muestra correcta no prueba el resto. La prueba profunda segura verifica espacio libre, no archivos existentes. La destructiva deja una pequeña reserva, no prueba área no particionada ni permite identificar sectores físicos. Los desplazamientos del informe son lógicos dentro de archivos.

SMART y caché

Muchas memorias no exponen SMART. La caída de velocidad puede deberse a caché, temperatura, puerto o actividad del sistema; se registra como indicio. El tiempo de llenado es extrapolación y puede aumentar.
